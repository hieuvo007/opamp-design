# Two-Stage CMOS Op-Amp Design

This repository contains the design, schematic, and simulation files for a **Two-Stage CMOS Operational Amplifier** using 0.18µm process.

## Project Overview
- **Objective**: Design a high-performance CMOS Op-Amp for analog circuit applications.
- **Topology**: Two-stage architecture with Miller compensation.
- **Technology**: 0.18µm CMOS process.

## Repository Structure
- `schematic/`: Contains Xschem schematic files (`.sch`).
- `sim/`: Contains SPICE simulation scripts (`.spice`, `.cir`) and output waveforms.
- `doc/`: Design specifications, reports, and technical documentation.

## Simulation Setup
1. Ensure you have **Xschem** and **Ngspice** installed on your Ubuntu system.
2. Navigate to `sim/` folder.
3. Run the simulation using the command: `ngspice <your_file.spice>`
